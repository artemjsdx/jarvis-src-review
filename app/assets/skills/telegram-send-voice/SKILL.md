## Когда применять
«Отправь Маше голосовое», «скинь этот файл в рабочий чат», «скачай фото из чата с семьёй». Для текста используйте telegram-reply.

## Предусловия
- Права «Чтение и отправка» или «Всё» для отправки; «Чтение» достаточно для скачивания.
- Файл лежит в песочнице приложения или в известном пути на телефоне. Путь проверяется до вызова инструмента.
- Чат и аккаунт известны (см. telegram-overview).

## Шаги
1. Проверьте файл: `mcp_call` инструментом чтения нет, поэтому проверьте путь через файловый инструмент приложения (существует, размер, расширение).
2. Прочитайте вслух, что уйдёт: «Отправлю файл <имя>, <размер>, в чат «<название>» от «<метка>». Отправить?» Ждите «да».
3. Голосовое: `mcp_call {"server":"telegram","tool":"send_voice","arguments":{"chat_id":"<id>","file_path":"<путь>","account":"<метка>"}}`. Если сервер вернул ошибку формата, отправьте тот же файл через `send_file` с `force_document` и скажите пользователю, что ушёл файл, а не голосовое.
4. Другой файл, фото или видео: `mcp_call {"server":"telegram","tool":"send_file","arguments":{"chat_id":"<id>","file_path":"<путь>","caption":"<подпись или пусто>","account":"<метка>"}}`. Альбом из нескольких файлов — `send_album` с `file_paths`.
5. Скачать вложение: сначала `get_media_info {"chat_id":"<id>","message_id":<id>,"account":"<метка>"}`, затем `download_media {"chat_id":"<id>","message_id":<id>,"file_path":"<путь в песочнице>","account":"<метка>"}`.

## Как проверить результат
Ответ `send_file` или `send_voice` содержит id сообщения. Для скачивания: файл по `file_path` существует и его размер совпадает с `get_media_info`.

## Ловушки
- Файлы больше 50 МБ Telegram не принимает для обычного аккаунта: проверьте размер до отправки.
- `send_file` с `force_document` шлёт файлом без предпросмотра; голосовое всегда через `send_voice`.
- Не скачивайте и не отправляйте файлы из системных папок и файлы с паролями, ключами, сессиями (`.env`, `*.session`, `keys.*`). Откажитесь и объясните почему.
- Пересылка (`forward_message`) — это тоже отправка, подтверждение обязательно.

## Откат
Отправленный файл удаляется `delete_message` по `message_id`, по просьбе пользователя. Скачанный файл удаляется файловым инструментом приложения, если пользователь попросил.
