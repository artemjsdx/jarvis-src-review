## Когда применять
Инструмент adb_status показывает, что ADB не сопряжён или не подключён, а команды через adb_shell нужны для задачи.

## Предусловия
- Телефон и источник команд в одной Wi-Fi сети. Адрес 127.0.0.1 не подходит: нужен IP телефона в сети.
- На телефоне открыт экран «Отладка по Wi-Fi» (Настройки → Для разработчиков). Пользователь сам открывает окно «Сопряжение с устройством»: оно показывает IP, порт сопряжения и 6-значный код.

## Шаги
1. Вызови `adb_status`. Если состояние «connected», больше ничего не делай.
2. Попроси пользователя назвать IP, порт сопряжения и 6-значный код из окна «Сопряжение с устройством».
3. Вызови `adb_pair` с host=IP, pairing_port=порт сопряжения, code=код.
4. Попроси порт подключения с основного экрана «Отладка по Wi-Fi». Это другой порт, не порт сопряжения.
5. Вызови `adb_connect` с host=IP и port=порт подключения.
6. Проверь: `adb_status` должен показать соединение, затем `adb_shell` с командой `getprop ro.product.model`.

## Как проверить результат
`adb_shell` вернул ok=true и название модели телефона. Только после этого говори пользователю, что ADB подключён.

## Ловушки
- Порт сопряжения и порт подключения разные. Если подставить сопряжение в `adb_connect`, подключение не пройдёт.
- Код сопряжения живёт недолго. При ошибке попроси открыть окно заново и взять новый код.
- При смене Wi-Fi сети IP и порты меняются: старое подключение не работает, пройди шаги заново.

## Откат
`adb_disconnect` отключает Wi-Fi соединение. Сопряжение сохраняется на телефоне; чтобы его снять, пользователь удаляет устройство в «Отладка по Wi-Fi».
