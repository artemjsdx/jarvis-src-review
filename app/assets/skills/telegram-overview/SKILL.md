## Когда применять
Пользователь спрашивает «какие у меня аккаунты», «какой аккаунт по умолчанию», «что ты можешь в телеграме», или перед первой операцией в сессии, если неясно, с каким аккаунтом работать.

## Предусловия
- Сервер Telegram работает: в настройках «Telegram-аккаунты» статус «работает». Иначе см. навык telegram-flood-and-limits, раздел «сервер не отвечает».
- Список аккаунтов известен из системной строки «Telegram: аккаунты …». Если строки нет — аккаунтов не подключено, предложите войти в настройках.

## Шаги
1. Перечислите метки аккаунтов из системной строки (например `owner`, `work`). Метка — это параметр `account` у каждого инструмента.
2. Если аккаунт один, `account` можно не указывать для чтения; для записи указывайте всегда.
3. Если аккаунтов несколько, для чтения без `account` инструменты (например `list_chats`) вернут данные по всем аккаунтам. Для записи `account` обязателен — без него сервер откажет.
4. Чтобы узнать, что доступно, найдите инструмент через `mcp_search {"server":"telegram","query":"<слово>"}`, затем вызывайте `mcp_call {"server":"telegram","tool":"<имя>","arguments":{...}}`.
5. Чтобы показать права: спросите у приложения режим «Права агента» (чтение, чтение и отправка, всё) — он общий для всех аккаунтов.

## Как проверить результат
`mcp_call {"server":"telegram","tool":"get_me","arguments":{"account":"<метка>"}}` возвращает имя и @username нужного аккаунта. Если вернулась ошибка «не авторизован», аккаунт нужно войти заново в настройках.

## Ловушки
- Права общие для всех аккаунтов: «только чтение» для одного означает «только чтение» для всех. Сервер применяет их до запуска, это не настройка агента.
- Сообщения чужим людям — необратимы. Не выбирайте аккаунт сами, если в запросе нет метки и есть два аккаунта: спросите.
- Не пересказывайте личную переписку целиком без запроса: сводка и поиск достаточны.
- Имена инструментов из PyPI-пакета `telegram-mcp` не относятся к нашему серверу. Используйте только имена из `mcp_search`.

## Откат
Чтение ничего не меняет, откат не нужен. Права и подтверждения меняются только в настройках приложения, агент их не трогает.
