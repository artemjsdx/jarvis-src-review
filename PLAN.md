## Архитектура (кратко)

- `app.jarvis.core.*` — чистая Java без `android.*`: SSE-парсер, клиент чата, агентский цикл, инструменты, загрузчик,
  безопасная распаковка. Тестируется на JVM в Termux (`bash build.sh test`).
- `app.jarvis.*` — Android: Application, служба переднего плана, голос (захват/VAD/wake/STT/TTS), плеер, UI на Canvas/View
  (без AndroidX, без XML-раскладок), журнал, БД SQLite, хранилище секретов (Android Keystore).
- Одно приложение, один процесс; один foreground-service держит микрофон/плеер/долгие задачи.
- Данные: `filesDir/sandbox/{work,inbox,downloads,music,docs,tmp}`, SQLite для чата/запусков/вызовов/памяти/журнала.

## Принципы

1. Успех сообщает инструмент, не модель. 2. Побочные эффекты не повторяются автоматически после сбоя.
3. Всё тяжёлое — вне UI-потока; очереди ограничены. 4. Секреты не попадают в журнал, документы и архивы.
5. Любая функция в интерфейсе либо работает, либо отсутствует.

### Работа с GitHub

1. Отдельные коммиты в `fix/ui-glass-layout` без изменения `main` и оригинального `app.jarvis`.
2. После каждого набора запуск `.github/workflows/build-review-apk.yml`: JVM-тесты, build.sh, apksigner, package id, secret scan и artifact.
3. При ошибке CI — исправление в той же ветке, повторный прогон. Никакого статуса [x] до фактической проверки.
4. Проверка на телефоне по коммиту из «Дополнительно → Версия»; скриншоты в двух темах и замер `dumpsys gfxinfo`.
5. Только подтверждённые результаты переводят строки REQ.md из [~] в [x].

### Критерии качества стекла

- `GlassSurface` или `Glass.mark` означает фон, который требует backdrop blur; стандартные полупрозрачные элементы должны использовать эту общую семантику.
- Нельзя считать иконку, ripple, полупрозрачный текст или затемняющий scrim самостоятельной размытой поверхностью.
- Blur-карта строится в host coordinates; видимая часть ограничена viewport; снимок не должен расходиться со скроллом.
- Общая маска и общий RenderEffect без лишних GPU проходов; `GlassLevel.AUTO` сохраняет защиту производительности.
- Сначала убедиться, что слой фонового свечения не перекрывает controls; blur не может маскировать ошибку порядка слоёв.
