## Архитектура (кратко)

- `app.jarvis.core.*` — чистая Java без `android.*`: SSE-парсер, клиент чата, агентский цикл, инструменты, загрузчик,
  безопасная распаковка. Тестируется на JVM в Termux (`bash build.sh test`).
- `app.jarvis.*` — Android: Application, служба переднего плана, голос (захват/VAD/wake/STT/TTS), плеер, UI на Canvas/View
  (без AndroidX, без XML-раскладок), журнал, БД SQLite, хранилище секретов (Android Keystore).
- Одно приложение, один процесс; один foreground-service держит микрофон/плеер/долгие задачи.
- Данные: `filesDir/sandbox/{work,inbox,downloads,music,docs,tmp}`, SQLite для чата/запусков/вызовов/памяти/журнала.

## Принципы

1. Успех сообщает инструмент, не модель. 2. Побочные эффекты не повторяются автоматически после сбоя.
3. Всё тяжёлое — вне UI-потока; очереди ограничены. 4. Секреты не попадают в журнал, документы и архивы.
5. Любая функция в интерфейсе либо работает, либо отсутствует.
