# Настройки speed2 (для набора UI, set1)

Все ключи хранятся в `Settings` (plain JSON). Значения по умолчанию — те, что читает код.

| ключ | тип | по умолчанию | значение | подпись (рус.) | подсказка (рус.) |
|---|---|---|---|---|---|
| `direct.confirm` | enum: fast / live / auto | `auto` | как подтверждать прямые команды: шаблон из кэша, фраза модели или по скорости сети | Подтверждение команд | «Быстро» — сразу фраза из кэша. «Живо» — модель формулирует по результату. «Авто» — быстро, если модель сейчас медленная или сеть слабая. |
| `ack.mode` | enum: off / voice / always | `voice` | короткая реплика «Секунду.» пока модель думает | Реплика ожидания | Выкл — никогда. Голос — только для голосовых команд. Всегда — и для текстовых. |
| `ack.delayMs` | int, мс | `900` | через сколько мс без ответа включить реплику | Задержка реплики | Реплика звучит, если ответ не начался за столько миллисекунд после конца речи. |
| `ack.phrases` | string, фразы через «\|» | пусто (встроенный список) | свои реплики ожидания | Фразы ожидания | Разделитель «\|». Пустое поле — стандартные фразы. |
| `tts.lookahead` | bool | `true` | синтезировать следующий кусок ответа во время проигрывания | Опережающий синтез | Уменьшает паузу между предложениями. Выключить — если нужен прежний порядок. |
| `tts.prewarm` | bool | `true` | заранее готовить частые фразы в кэше (только бесплатные провайдеры) | Заготовленные фразы | Фразы подтверждения и ожидания звучат без задержки синтеза. |
| `stt.endSilenceMs` | int, мс (300–1500) | `550` | тишина, после которой фраза считается законченной | Пауза конца фразы | Меньше — быстрее ответ, но фразы режутся на паузах. |
| `stt.holdUnfinished` | bool | `true` | ждать продолжения, если фраза оборвана на «и», «в», запятой | Ждать продолжения | Если фраза кончается союзом или предлогом, ассистент ждёт до 1,6 с. |
| `llm.hedgeMs` | int, мс | `4000` | через сколько мс без первого токена запустить запасной маршрут параллельно | Запасной маршрут через | 0 — выключено. Запасной маршрут оплачивается, даже если он проиграл. |
| `tools.groups` | bool | `true` | показывать модели только нужные инструменты: ядро и группы (музыка, файлы, веб, терминал, ADB, память, навыки, настройки, история), остальные подключаются по словам запроса, по недавним ходам или вызовом `tools_enable` | Инструменты по требованию | Выкл — все инструменты в каждом запросе, как раньше. Вкл — только нужные, запрос короче. Страница «Контекст и промпт». |
| `tools.fullEvery` | int (0–100) | `0` | при включённых группах каждый N-й запрос пользователя в чате (счёт с 1, «очистить контекст» начинает заново) уходит со ВСЕМИ инструментами, как напоминание; 0 — никогда, 1 — каждый запрос | Все инструменты каждые N запросов | Раз в N запросов уходит полный список. 0 — никогда, 1 — в каждом. Страница «Контекст и промпт». |
| `llm.contextChars` | int | `60000` | (уже есть) бюджет контекста | — | — |

Служебный файл: `latency.json` в каталоге данных приложения (скользящие задержки LLM; можно удалить).

# Настройки скорости голоса: распознавание и обращение

Файл общий для веток скорости. Каждая ветка пишет свой раздел; раздел `speed3` описывает ключи, которые читает `VoiceController`
и которые ещё не выведены в интерфейс (вывод — задача `set1`).

## speed3: распознавание речи и обращение (P-02, P-03)

| ключ | значения | по умолчанию | что делает |
|---|---|---|---|
| `stt.format` | `auto`, `opus`, `flac`, `wav` | `auto` | Контейнер, в котором аудио уходит к провайдеру распознавания. `auto` — выбор по времени: кодирование + отправка при измеренной скорости отдачи (по прошлым запросам; пока не измерено, считается 1,6 Мбит/с). Быстрая связь: WAV без кодирования; средняя: FLAC (≈0,1 с на кодирование, 40 % размера); медленная (менее ≈1 Мбит/с для обычной фразы): Opus (кодирование 0,3–0,6 с, 5–8 % размера). Явное значение перекрывает выбор. |
| `stt.hedgeMs` | целое, мс | `3000` | Через сколько миллисекунд без ответа первого провайдера цепочки параллельно запускается следующий. Первый ответ с текстом побеждает, остальные отменяются. `0` — все провайдеры сразу; очень большое значение — последовательная цепочка. |
| `wake.engine` | `auto`, `local`, `cloud` | `auto` | Как искать обращение «Джарвис». `auto`: локальная модель Vosk, если она установлена и загружается; иначе облако. Локальное срабатывание под `auto` подтверждает облако (тот же фрагмент речи должен дать слово «Джарвис» в расшифровке). `local`: только локально, облако используется лишь для текста команды после обращения, без подтверждения. `cloud`: каждая фраза уходит в облачное распознавание (ограничено 10 фразами в минуту). |

Замечания:
* Ключи читаются через `Settings.STT_FORMAT`, `Settings.STT_HEDGE_MS`, `Settings.WAKE_ENGINE` (`app/src/main/java/app/jarvis/data/Settings.java`).
* Локальная модель `vosk-model-small-ru-0.22` (≈ 46 МБ, SHA-256 закреплён в `WakePack`) ставится через `WakePack`. Без установленной модели `auto` работает как `cloud`.
* ElevenLabs Scribe пока принимает только FLAC и WAV: формат OGG/Opus для него не включён, пока не проверен на живом запросе.
* Groq принимает OGG/Opus (проверено живым запросом, см. `docs/SPEED.md`, раздел 9).
