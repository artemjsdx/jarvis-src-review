# Проверка на телефоне — search1 (X-04, X-06, S-15, S-13)

Не выполнено на устройстве: телефон был недоступен по ADB (Wave 3). Ниже — шаги для запуска, когда ADB снова включён.
Перед началом: `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569`, сборка `build/outputs/search1.apk`
(`JV_APP_ID=app.jarvis.search1`, ярлык «Jarvis [search1]»). Установку и открытие приложения делает владелец или ведущий агент.

1. Установка: `adb -s $D install -r build/outputs/search1.apk`. Открыть «Jarvis [search1]» один раз. Файлы `triggers.json` при первом запуске создаются сами.
2. Поиск по чатам: создать чат, написать «Купи билет на поезд в Минск». Открыть шторку, ввести «поез».
   Ожидание: заголовок чата, под ним фрагмент сообщения с жирным «поез…», время и роль («Вы»/«Джарвис»). Чат без совпадения по тексту, но с совпадением по названию, идёт ниже обычным списком.
3. Переход к сообщению: нажать на фрагмент. Ожидание: открывается этот чат и лента прокручена к сообщению, а не к низу. Повторить, когда чат уже открыт.
4. Инструмент `session_search`: в чате спросить «что мы говорили про поезд?». Ожидание: карточка инструмента `session_search` с результатами, ответ ссылается на найденное.
5. Страница «Контекст и промпт» (Настройки, раздел «Подключение»):
   a. Полосы и цифры: «Правила и окружение» самая большая часть, «Инструменты (N)» вторая. Итог «N токенов · M симв. · P% окна».
   b. «Показать системный промпт» — шит только для чтения, текст можно выделить, закрывается без изменений.
   c. Бюджет памяти 500 → итог уменьшился (при непустой памяти). Вернуть 2000.
   d. «Сбросить правила к умолчанию» → диалог подтверждения → значения 2000 / 60000 / 8, тосты «Настройки промпта сброшены».
6. Напоминание: поставить N = 2, отправить два сообщения подряд. Через MCP: `python3 tools/jv.py agent_prompt_dump '{"session":"<id>"}'`.
   Ожидание: в `report` для второго хода в блоке времени есть «напоминание: отвечай одной-двумя короткими фразами…»; системный промпт не меняется.
7. Фразы-триггеры (Настройки, раздел «Музыка»): есть предустановка «я проснулся · … · папа проснулся» (без нейросети, `morning`).
   a. Выключить тумблер, сказать или ввести «доброе утро». Ожидание: приветствия нет, команда уходит в модель.
   b. Включить, ввести «доброе утро» → приветствие и любимая песня (если выбрана), ответ без вызова модели (в трассе нет `llm`).
8. Новый триггер «включи радио», без нейросети, действие `tools.call:music_play:{"path":"music/<файл>.mp3"}`. Ввести «включи радио».
   Ожидание: музыка играет, ответ «Включаю …». Сбой (несуществующий файл) → «Не получилось: …», без «включаю».
9. Триггер через нейросеть: фраза «устал», инструкция «спроси, нужен ли перерыв». Ожидание: модель отвечает по инструкции; в `report` есть «сработал триггер «устал»».
10. Создание через чат: «запомни: когда я говорю “пора спать”, выключай музыку». Ожидание: агент сначала спрашивает подтверждение, затем вызывает `trigger_save`, и фраза появляется в списке.
11. Тёмная и светлая тема: сравнить экран с `build/preview/context_*.png` и `triggers_*.png`.
12. Пользователь без ключа/сети: поиск по чатам и `session_search` работают локально; проверить, что нет ошибок в журнале.
13. Удаление: `adb -s $D uninstall app.jarvis.search1`.

Признаки проблем: пустой результат поиска по слову, которое точно есть в чате; прокрутка не к сообщению; триггер срабатывает на обычную фразу внутри длинной команды.
