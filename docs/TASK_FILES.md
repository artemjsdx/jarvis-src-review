## Already diagnosed and fixed by the lead (in master; merge master first, do not redo)
Preview-based diagnosis (`FilesProbeScenes` prints the view tree with sizes) found why the owner saw an empty screen with a floating "песочница":
1. `Ui.space()` returned a bare `View`; with WRAP_CONTENT a bare View measures like MATCH_PARENT, so the toolbar row (spacer + `lpw(1f)`) became as tall as the whole screen and the list area got 0 px height. `Ui.space` now returns `android.widget.Space`.
2. The root folder cards were added with `Ui.lpm(0, -2, ...)` = width 0 WITHOUT weight, so they were 0 px wide. Now `Ui.lpw(1f)` + margins.
3. `ListView.setEmptyView` also showed "Пустая папка" on top of the root cards; visibility is now managed in `apply()`.
4. Gotcha for everyone: a `LinearLayout` with `gravity=CENTER_VERTICAL` (the default of `Ui.row`) lays out a child at `(space-h)/2 + topMargin - bottomMargin`, so a child with ONLY a bottom margin is shifted UP by half of it and clipped by the row. Use top gravity or symmetric margins. (Fixed for the folder-card rows.)
