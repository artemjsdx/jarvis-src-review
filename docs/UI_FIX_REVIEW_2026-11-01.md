## 2. Производительность — PERF-11

- `GlassHost` теперь отслеживает изменение дочернего контента и не делает лишний software capture при неизменном фоне за стеклянным overlay.
- `BlurLayer` очищает весь snapshot во избежание старых прямоугольных фрагментов, но рисует дорогое содержимое только в области overlay с запасом 40dp на размытие.
- **На SwiftShader метрики неоднозначны:** по разным группам число пропусков кадров меняется в обе стороны. Поэтому **PERF-11 не считается полностью закрытым**. Замер на физическом GPU и при прокрутке/анимации обязателен до утверждения ускорения.

Поэтому не следует считать TalkBack-проверку полностью закрытой.

**Важно про blur:** требование размытия **каждой** полупрозрачной поверхности ещё не подтверждено отдельным тестом поверх насыщенного фона; полный визуальный результат и плавность на vivo не проверены.

Система: Android API 35, Google APIs Pixel 6, экран 1080×2400, анимации 0.5×, программный GPU SwiftShader. В каждом аудите — последовательная прокрутка всех 16 страниц настроек, 6 разделов дока, вкладок студии и шторки чатов. Скриншоты, XML и видео переходов находятся в `jarvis-ui-audit-{a,b,c,d}` артефактах. APK извлекается из `jarvis-uifix-apk`.

**Ограничения:** нет реальных Telegram-аккаунтов, API-ключей, разговоров, аудиосинтеза и пользовательских файлов. Нельзя подтверждать производительность vivo или полный визуальный blur через шторку поверх длинных сообщений. Программа `uifix` не заменяет основной пакет. Контраст и названия элементов проверены кодом, тестами и XML; качество на другом масштабе шрифта требует проверки.
