# Дополнительные поисковые провайдеры Jarvis (02.11.2026)

## Правила архитектуры
- **Стандартный** `web_search` остаётся без изменений. Его цепочка Brave → Tavily → Exa → OpenRouter → SearXNG → DuckDuckGo по-прежнему существует в `WebConfig`.
- **Дополнительный** `web_search_extra(provider, query, limit)` работает только с явно подключённым и проверенным сервисом. Агент выбирает провайдера, а не делает дорогой одновременный вызов всем.
- Встроенный `web_provider_guide(provider)` выдаёт отдельную инструкцию для каждого провайдера: сильная сторона, тарификация, ограничения, ссылка на документацию и пример вызова.
- В настройках есть защищённое сохранение ключа, тест настоящим поисковым запросом, показатель задержки, выключение без удаления ключа.
- Проверка связывается с SHA-256 отпечатком конкретного ключа. Через семь дней или после замены ключа нужна новая проверка; старый статус не считается подтверждением работы.
- **Дополнительные MCP**: готовые установки Parallel и Exa по HTTPS Streamable HTTP, включаются только после успешного подключения и обнаружения search tool. Отключение и контроль инструментов — в существующей странице MCP.

## Дополнительно исследованные — не выдавать за реализованные
- **SearXNG** — самостоятельный сервер, уже поддерживается стандартным Jarvis поиском. Требует инстанса с включённым JSON.
- **DuckDuckGo HTML** — в стандартной цепочке; антибот HTTP 202 может ломать запросы.
- **YaCy** — self-hosted распределённый индекс с собственным API; зависит от железа и выбранных peers.
- **Serpex** — 200 стартовых кредитов, не повторяющаяся безлимитная квота. https://serpex.dev/
- **Firecrawl** — поиск и извлечение страниц; бесплатные кредиты, расход зависит от операции. https://www.firecrawl.dev/pricing
- **Jina Reader** — поиск/извлечение по токенной квоте; нельзя считать постоянным безлимитом. https://jina.ai/
- **Perplexity Search** — платный API, есть Fast, но отсутствие общего бесплатного пакета требует осторожности. https://docs.perplexity.ai/
- **You.com** — API для поиска и ответов, проверьте актуальную квоту после регистрации. https://you.com/platform
- **Brave MCP**, **Tavily MCP** — доступны как внешние MCP, если сервер и авторизация их позволяют; не установлены автоматически.
- **Волкэнджин/Doubao ARK Search (Китай)** — есть разработки и MCP-обёртки, но нет подтверждённой универсальной безлимитной квоты для русских запросов.
- **Baidu/360/Sogou HTML** — без официального подходящего договора/ключа массовое скрейпинг-решение для мобильного клиента хрупкое; не добавлено как обещание «фул фри».
- **Google Custom Search JSON API** — закрыт для новых клиентов; не рассматриваем как доступный новичку.
- **Bing Web Search API** — ранее прекращена выдача ключей; не рекомендуем как новый free-tier.

## Обнаруженные общие ошибки и исправления
- В студии TTS все карточки открывали **один и тот же шаблон** из трёх фраз. Исправлено: `ProviderGuides.tts` и `ProviderGuides.stt` с индивидуальными объяснениями под каждый движок.
- Ранее вопросики показывали много текста сразу. `HelpPopup` теперь рисует нативную мини-схему (Выбор → Результат, Речь → Команда, Запрос → Источники) и перелистываемые шаги, без внешних ресурсов.
- `SettingsPage` автоматически ставит вопросик около стандартных заголовков, `SectionHelp` уже содержит уникальные тексты для большинства разделов. Для появившегося раздела поиска подсказки есть на карточках.
- В `OverlayHost` фон диалогов/шторок/toast рисовался двумя почти непрозрачными слоями, скрывавшими действительное размытие. `GlassDrawable.overlayFrost()` теперь применяет более прозрачную заливку к оверлеям; blur архитектуры `GlassHost` не заменялся.

## Инструкция тестирования
1. Откройте Настройки → Дополнительный веб-поиск. Стандартный поиск должен оставаться работающим.
2. Сохраните ключ любого сервиса. В карточке он должен отображаться только маской.
3. Нажмите «Проверить» — выполнить запрос `Android official documentation`, проверить минимум одну HTTPS-ссылку.
4. Проверьте появление включённого сервиса в контексте агента. `web_provider_guide` должен объяснить разницу. `web_search_extra` не должен работать при выключенном провайдере или после замены ключа.
5. Отключите сервис — ключ должен сохраниться.
6. Попробуйте установку Parallel MCP без ключа. При ошибке сервер должен остаться выключенным, а не считаться работающим.
7. Откройте вопросики TTS, STT, нового раздела, листайте страницы, проверьте, что карточки не содержат дублирующихся шаблонов.
8. На Android 35 с режимом стекла «Полная» проверьте, что через шторку видно размытый, не резкий фон и текст остаётся читаемым. Также проверьте светлую тему и режим «Авто».
