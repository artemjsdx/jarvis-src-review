# Настройки звука и микрофона (для экрана настроек, Z-01…Z-04)

Все ключи хранятся в `Settings` (обычный JSON, не секреты). Значения по умолчанию заданы в коде (`core/audio/CueSettings`, `core/voice/TtsCapabilities`), поэтому пустой ключ = значение по умолчанию. Некорректное значение тоже падает в умолчание.

| ключ | тип | по умолчанию | подпись в UI | подсказка |
|---|---|---|---|---|
| `cue.enabled` | bool | `true` | Звуковые сигналы | Короткий звук при начале записи, конце записи и при ошибке. Выключает только звук; вибрация управляется `cue.haptic`. |
| `cue.start.enabled` | bool | `true` | Сигнал начала | Звучит, когда Джарвис начал слушать (по «Джарвис» или по кнопке микрофона). |
| `cue.stop.enabled` | bool | `true` | Сигнал конца | Звучит, когда запись закончилась сама (пауза в речи) или её остановили вручную. |
| `cue.error.enabled` | bool | `true` | Сигнал «не услышал» | Звучит, когда команда не распознана или не была сказана за 7 секунд. |
| `cue.set` | строка | `crystal` | Набор по умолчанию | Идентификатор набора: `crystal`, `marimba`, `water`, `bell`, `breath`, `piano`, `musicbox`, `harp`, `bowed`, `click` (встроенные, см. `app/assets/sounds/sounds.json`) и `oga_clicks` (после установки пакета CC0). Сигнал «не услышал» всегда берётся отсюда. |
| `cue.start.set` | строка | `""` | Звук начала | Набор для сигнала начала. Пусто — как `cue.set`. Неизвестный id тоже падает в `cue.set`. |
| `cue.stop.set` | строка | `""` | Звук окончания | Набор для сигнала конца. Пусто — как `cue.set`. Выбирается отдельно от начала. |
| `cue.volume` | число | `0.55` | Громкость сигналов | От 0.1 до 1.0. Множитель к системной громкости уведомлений/ассистента. |
| `cue.haptic` | bool | `true` | Вибрация при начале и конце | Одиночный тик при начале, двойной при конце (18 мс и 2×14 мс). Не вибрирует во время звонка. |
| `cue.custom.start` | строка | `""` | Свой звук начала | Имя файла в `filesDir/cues/` (ставит `CueImport.importFile`). Пусто — берётся набор. Файл: OGG/WAV/MP3, до 300 КБ, до 3 с. |
| `cue.custom.stop` | строка | `""` | Свой звук конца | То же для сигнала конца. Сигнал «не услышал» всегда из набора. |
| `tts.speed` | число | `1.0` | Скорость речи | От 0.7 до 1.4. Работает в ElevenLabs (0.7–1.2), Edge (SSML rate), Google Translate (только медленнее, ниже 0.9). Silero и OpenRouter скорость игнорируют. F5 получает значение, но не проверено, меняет ли темп сервер. |

## Что делают действия (не ключи)

* Экран «Звук и микрофон» (`ui/settings/SoundsPage`, в группе «Голос» списка настроек): переключатели сигналов, два выбора (начало и конец, каждый с ▶), громкость, вибрация, «Свой файл…», скачивание пакета, строка состояния микрофона.
* Предпросмотр — `Cues.previewSet(setId, Kind)` (один клип набора) и `Cues.previewFile(name)` (свой файл). Только по нажатию ▶, никогда автоматически. Клип, ещё не загруженный, играет сразу после загрузки.
* Каталог для выбора — `Cues.sets()` (встроенные и, если установлен, пакетные). `Cues.release()` освобождает пул звуков страницы.
* Свой файл — `CueImport.importFile(ctx, uri, "start" | "stop")` возвращает имя файла; сохранить его в `cue.custom.start` / `cue.custom.stop`. Ошибки приходят с русским текстом (формат, размер, длина, нет звука).
* Пакет CC0 — `CueImport.installPack(ctx, journal, progress, cancel)` (фоном): скачивает zip с OpenGameArt (231 КБ), проверяет SHA-256, распаковывает. Набор `oga_clicks` появляется в `Cues.availableSets()` только после установки. Проверено на стенде (см. `docs/SOUNDS.md`).
* Строки состояния (`core/audio/CueSummary`): «Хрусталь · вкл» / «начало: … · конец: …» / «выключены»; микрофон: причина уступки или «Джарвис слушает…».

## Уступка микрофона (Z-03) — без ключа

Работает всегда, отдельного переключателя нет. Состояния пишутся в журнал (категория «Обращение», INFO) и в строку состояния голоса:
«Микрофон занят другим приложением», «Идёт звонок: Джарвис не слушает», «Микрофон снова у Джарвиса», «Микрофон не освободился: прослушивание остановлено» (после 3 неудачных попыток; обращение выключается, включить можно снова).

## Индикатор «слышу» (Z-02) для экрана

* Уровень микрофона 0…1: `JarvisListener.onLevel(float)` (как раньше, для орба).
* Фаза захвата: `JarvisListener.onListening(ListeningIndicator)` — `LISTENING` (начало записи), `HEARD` (речь закончилась), `FAILED` (ошибка или тишина), `OFF` (отмена).
