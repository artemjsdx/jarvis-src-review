# DEVICE_CHECKLIST ci1 — что проверить на телефоне владельца (ADB сейчас выключен)

Нужно только для двух правок в приложении; остальное проверено эмулятором (docs/CI.md).

1. Установить личную сборку (`JV_APP_ID=app.jarvis.ci1 bash build.sh debug` или отдельный APK) с правками ci1; либо дождаться APK из CI `ci-apk`.
2. Открыть «Агент», создать две сессии (обычную и вторую), переключиться между ними через меню «≡» (`ui_tap desc=Сессии`) — ожидаемо: заголовок в шапке меняется на название выбранной сессии (раньше оставался старым).
3. Настройки → Внешний вид → «Светлая»: ожидаемо сразу светлая тема на открытом экране; затем вернуть «Тёмная».
4. Длинный ответ с Markdown (`**жирный**`, `## заголовок`): ожидаемо видны сырые символы разметки — это известное ограничение, зафиксировать, не чинить здесь.
5. Блок действий из нескольких инструментов: подписи «Файлы: список», «Поиск» — ожидаемо русские глаголы («список», «поиск»), в аргументах нет `\/` вместо `/`.

Результат записать владельцу в ответ; ничего на телефон не ставить без его разрешения.
