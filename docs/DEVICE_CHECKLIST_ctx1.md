# Проверка на телефоне: навыки (SKILL.md) и память v2 (ctx1)

Не выполнено: телефон был недоступен по ADB (Wave 3). Все шаги ниже — чеклист для владельца или следующего агента, когда ADB вернётся. Текстовый чат; звук из динамика и микрофон не нужны.

Переменные: `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569`. Пакет: `app.jarvis.ctx1`.

## 1. Установка варианта

1. `adb devices` — телефон должен быть в списке. Если нет, подождать 30 с и повторить (не pair, не connect).
2. `bash tools/with-screen.sh adb -s $D install -r build/outputs/ctx1.apk` — установка.
3. Ожидаемо: «Success». Ярлык «Jarvis [ctx1]».

## 2. Встроенные навыки установились

1. Открыть Jarvis [ctx1] (`bash tools/with-screen.sh adb -s $D shell am start -n app.jarvis.ctx1/app.jarvis.MainActivity`).
2. В чате написать: «какие у тебя навыки?».
3. Ожидаемо: ответ вызывает `skills_list` и называет четыре навыка: termux-environment, web-research, adb-wifi-pairing, writing-skills. В карточке действия видно имя инструмента.
4. Файлы на диске (read-only): `adb -s $D shell run-as app.jarvis.ctx1 ls files/sandbox/skills` — ожидаемо четыре папки и файл `.seeded`. Если `run-as` недоступен для варианта, пропустить: п. 2.3 достаточно.

## 3. Просмотр и правка навыка через ассистента

1. Написать: «открой навык writing-skills».
2. Ожидаемо: вызов `skill_view`, в ответе кратко о навыке, без зачитывания всего текста.
3. Написать: «в навыке writing-skills допиши в ловушки строку: проверяй коды сопряжения на срок».
4. Ожидаемо: вызов `skill_manage` с операцией `patch`; ответ «сохранено». Повторить п. 2: строка на месте.
5. Негативная проверка: «создай навык с именем Bad Name». Ожидаемо: ошибка «Имя навыка …: только строчные латинские буквы…», ничего не создано (п. 2.1 покажет прежний список).

## 4. Память: факты и стиль ответа

1. Написать: «запомни: я предпочитаю короткие ответы». Ожидаемо: `memory_save` с ключом и значением-фактом.
2. Написать: «меньше точек в ответах». Ожидаемо: `memory_save` с `kind=style`.
3. Открыть экран памяти (раздел «Песочница», список памяти — найти на экране по месту): обе записи видны. Отдельных значков по виду пока нет (S-09/S-10, позже).
4. Бюджет: написать «запомни: <фраза около 400 символов>» четыре-пять раз, с разными ключами. Ожидаемо: при переполнении ответ «память заполнена: объедините или удалите записи»; ничего не сохранено; в результате инструмента указаны использовано и лимит (2000 по умолчанию).

## 5. Предложение сохранить навык

1. Написать многошаговую задачу, которая заставит модель вызвать не меньше четырёх инструментов (например: «создай заметку в docs/ с текстом один, потом прочитай её, потом проверь размер файла, потом удали»).
2. Дождаться ответа. Затем написать любую короткую фразу, например «спасибо».
3. Ожидаемо: в ответе на следующий запрос ассистент предлагает сохранить процедуру как навык одной фразой. Повторный такой же запуск в течение 30 минут предложение не повторяет.
4. Журнал (Настройки → Журнал): запись «Навык: …» появляется только после реальных `skill_manage`.

## 6. Голосовой режим не предлагает навык

1. Выполнить голосовой запрос, требующий четырёх инструментов (только если микрофон можно использовать в тот момент; иначе пропустить и отметить как не проверено).
2. Ожидаемо: подсказки «предложи сохранить навык» не появляется до следующего текстового запроса.

## 7. Нагрузка и регрессии

1. Открыть чат и выполнить обычный запрос «который час». Ожидаемо: без изменений по сравнению с основной сборкой; ответ не задерживается заметно (индекс навыков читается при каждом запросе, 4 навыка — миллисекунды).
2. Журнал: при запуске нет предупреждений «Встроенный навык … не установлен».

## 8. Очистка

1. `adb -s $D uninstall app.jarvis.ctx1`.
