# Настройки главного экрана (подсказки)

Для раздела настроек (`set1`). Ключи читаются через `Settings`; значения по умолчанию заданы в коде
`rt/Suggestions.java` и не требуют записи в `settings.json`.

| Ключ | Тип / значения | По умолчанию | Название в интерфейсе | Текст справки |
|---|---|---|---|---|
| `home.suggestions` | `true` / `false` | `true` | Подсказки на главном экране | Короткие подсказки под кнопкой микрофона. Когда выключено, показываются стандартные подсказки, и модель не вызывается. |
| `home.suggestions.mode` | `llm` / `static` | `llm` | Источник подсказок | «Из модели»: подсказки придумывает быстрая модель по вашим последним сообщениям, памяти и времени суток; не чаще 6 запросов в час. «Стандартные»: три готовые фразы, модель не вызывается. Без ключа провайдера всегда стандартные. |

Служебные ключи (в интерфейс не выводить):

- `home.suggestions.calls` — список времён запросов к модели за последний час (через запятую), для ограничения 6 в час.
- Файл `suggestions.json` в каталоге данных приложения — последние подсказки, время и отпечаток контекста (кэш).

Поведение, которое задают ключи:

- Подсказка на экране обновляется, когда главный экран открыт и кэш старше 10 минут, либо изменился контекст
  (новая реплика, память, часть суток, сейчас играет), а также через 8 секунд после завершения запуска агента.
- Нажатие на подсказку отправляет её агенту как обычное текстовое сообщение (`source = "text"`).
- Стандартные подсказки зависят от части суток: утро, день, вечер, ночь.
