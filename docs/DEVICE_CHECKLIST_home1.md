# Device checklist — home1 (подсказки на главном экране, H-01, H-03)

Нужно выполнить на vivo I2407, когда ADB снова доступен. Всё ниже касается только пакета `app.jarvis.home1`.

Подготовка:
1. `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569; adb devices` — устройство `$D` должно быть в списке.
2. Установить свою вариацию: `adb -s $D install -r build/outputs/home1.apk`.
3. Ключ OpenRouter для вариации ввести в Настройки → LLM (данные вариации свои, ключ основного приложения не трогать).
4. Запуск только под защитой экрана: `bash tools/with-screen.sh adb -s $D shell monkey -p app.jarvis.home1 -c android.intent.category.LAUNCHER 1`.

Проверки:
5. Главный экран, сразу после открытия: под орбом видна надпись состояния («Ожидание») и подсказка («Нажмите микрофон и скажите команду»).
   Ожидаемо: надпись видна. (В превью на стенде надпись не рисуется и в базовой версии тоже — проверить именно здесь.)
6. Через 1–10 с после открытия: тонкая полоса-шиммер сменяется тремя русскими подсказками (плавная смена ~160 мс).
   Снимок: `bash tools/dev-shot.sh` (проверить, что пакет в фокусе). Ожидаемо: 3 чипа, ≤ 28 символов каждый.
7. MCP `ui_tree` на главном экране: чипы видны как TextView с текстом подсказок; длинные подсказки переносятся на две строки и обрезаются многоточием.
8. Нажатие на чип: `bash tools/dev-tap.sh tap X Y` (или MCP `ui_tap`). Ожидаемо: в чате появляется реплика пользователя с текстом чипа,
   в БД есть запись `run`, журнал не содержит ответа прямой команды (`DirectCommands`), агент отвечает.
9. Журнал (MCP `journal`, категория LLM): после обновления строка «Подсказки обновлены: 3, … мс, модель …».
   Ключ не должен появляться ни в одной записи.
10. Обновление после диалога: отправить сообщение, вернуться на главный экран через 8–20 с. Ожидаемо: новая строка журнала,
    подсказки отражают последнее сообщение.
11. Лимит: за час не более 6 обращений к модели. Седьмое обновление в том же часу: строка «лимит запросов в час исчерпан», подсказки прежние.
12. Без сети: выключить Wi-Fi/мобильные данные, открыть главный экран. Ожидаемо: показаны прежние подсказки из кэша либо стандартные; приложение не зависает.
13. Настройка `home.suggestions.mode = static` (см. docs/HOME_SETTINGS.md): стандартные подсказки сразу, в журнале нет обращений к модели.
14. Настройка `home.suggestions = false`: то же поведение, что в п.13.
15. H-03 «Обращение «Джарвис»»: включить переключатель. Ожидаемо: надпись «Жду обращения», подсказка «Скажите «Джарвис», чтобы начать».
    Выключить: «Ожидание» / «Нажмите микрофон и скажите команду». MCP `voice_state` должен совпадать с надписью.
16. H-03 без устаревших подписей: команда голосом через инжект аудио (`voice_inject`, не микрофон). Во время «Слушаю» подсказка «Говорите, я слушаю»;
    после конца фразы под «Ожидание» не остаётся слов вроде «речь».
17. Инструмент: запрос, который вызывает инструмент (например, список файлов). Надпись «Выполняю инструмент», подпись — имя инструмента, только пока он работает.
18. Длинное имя провайдера/модели в верхней капсуле: многоточие посередине, одна строка.
19. Нажатие на чип во время работы агента: сообщение ставится так же, как при вводе с клавиатуры (без отмены текущего хода).
20. Выход: `bash tools/with-screen.sh adb -s $D uninstall app.jarvis.home1`.

Что не проверено на стенде: пункты 5–20 (нужен телефон); оболочка шара (`OrbView.setSkin`) — изображения пока нет, поведение
без изображения совпадает с прежним (проверено только сборкой и превью `HomeChatScenes`).
