# TASK VOICE — speech providers (TTS + STT) in pure Java

Owner dirs: `app/src/main/java/app/jarvis/core/voice/**` (except frozen contracts), tests `app/src/test/java/app/jarvis/core/voice/**`, live checks `app/src/test/java/app/jarvis/core/live/` (new files only).

**Frozen contract files (already written, read them first):** `core/voice/{AudioSpec,AudioSink,VoiceException,TtsRequest,Voice,ProviderInfo,ProviderStatus,ProviderConfig,TtsProvider,SttProvider,PcmAudio,SttOptions,SttResult}.java`. Also existing helpers you should reuse: `core/util/{CancelToken,J,Redactor}`, `core/net/Http`, `core/log/Journal`.

Goal: reliable Russian text-to-speech and speech-to-speech-recognition from a phone **without our own server**. All providers implement the contracts; the Android layer (not yours) plays the audio. Use `HttpURLConnection` + `javax.net.ssl` only (it must run on Android's runtime too — verify with `tools/art-apk.sh`).

## TTS providers to implement (research already done — facts below were measured on 2026-10-27)
1. **Edge Read Aloud** (`EdgeTts`, id `edge`, unofficial, no account/key). WebSocket over TLS (you must write a small RFC 6455 client: `WebSocketClient` — handshake with custom headers, masked client frames, text/binary/ping/pong/close, fragmented messages, read timeout, cancel by closing the socket). URL: `wss://speech.platform.bing.com/consumer/speech/synthesize/readaloud/edge/v1?TrustedClientToken=6A5AA1D4EAFF4E9FB37E23D68491D6F4&ConnectionId=<32 hex>&Sec-MS-GEC=<token>&Sec-MS-GEC-Version=2-143.0.3650.75`. Headers: `Pragma: no-cache`, `Cache-Control: no-cache`, `Origin: chrome-extension://jdiccldimpdaibmpdkjnbmckianbfold`, `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/143.0.0.0 Safari/537.36 Edg/143.0.0.0`, `Accept-Encoding: gzip, deflate, br, zstd`, `Accept-Language: en-US,en;q=0.9`, `Cookie: muid=<32 random hex uppercase>;`. Text messages to send: (1) `X-Timestamp:<JS date string>\r\nContent-Type:application/json; charset=utf-8\r\nPath:speech.config\r\n\r\n{"context":{"synthesis":{"audio":{"metadataoptions":{"sentenceBoundaryEnabled":"false","wordBoundaryEnabled":"false"},"outputFormat":"audio-24khz-48kbitrate-mono-mp3"}}}}\r\n` (2) `X-RequestId:<hex>\r\nContent-Type:application/ssml+xml\r\nX-Timestamp:<date>Z\r\nPath:ssml\r\n\r\n<speak version='1.0' xmlns='http://www.w3.org/2001/10/synthesis' xml:lang='en-US'><voice name='ru-RU-SvetlanaNeural'><prosody pitch='+0Hz' rate='+0%' volume='+0%'>ESCAPED TEXT</prosody></voice></speak>`. JS date string = `Thu Oct 28 2026 06:00:00 GMT+0000 (Coordinated Universal Time)`. Binary frames = 2-byte big-endian header length + header text (`Path:audio`) + MP3 bytes; text frame with `Path:turn.end` ends the stream. **The `Sec-MS-GEC` token is a custom (not standard) SHA-256/CS64 construction**: port `~/jarvis/.cache/research/edge_tts_pkg/edge_tts/drm.py` (`generate_sec_ms_gec_v2`, `_sha256_digest`, `_cs64_digest`, `_token_hash`) to Java **bit-exactly**; reference vectors from running the Python: ts=0 → `52BC7A17B50DFEC9-28C4394775C8751CD2F6859C030C06DB1489ACAB3B3A7651831FC26895177ED6`... (regenerate all vectors yourself with `python3 ~/jarvis/.cache/research/edge_tts_pkg/run_ref.py` and put them in a JUnit test; the token changes every 300 s window: ticks = (unix+11644473600) rounded down to 300 s, ×1e7). On HTTP 403 on the WebSocket upgrade, read the `Date` response header, adjust a clock-skew offset and retry once. Voices that worked: `ru-RU-SvetlanaNeural` (default), multilingual voices such as `en-US-AvaMultilingualNeural`, `en-US-BrianMultilingualNeural`, `fr-FR-RemyMultilingualNeural` (they pronounce Russian too); `ru-RU-DmitryNeural` failed with a dropped connection on 2026-10-27 — keep it in the list but surface the real error. `listVoices` may fetch `https://speech.platform.bing.com/consumer/speech/synthesize/readaloud/voices/list?trustedclienttoken=…&Sec-MS-GEC=…&Sec-MS-GEC-Version=2-143.0.3650.75` with the VOICE_HEADERS from `constants.py`. Map `TtsRequest.speed` to prosody rate. Output: `AudioSpec.mp3()`, stream MP3 chunks to the sink as they arrive. Measured on the bench: connect ≈ 0.8–1.7 s, first audio ≈ 1.5–3.5 s.
2. **Google Translate TTS** (`GoogleTranslateTts`, id `gtts`, unofficial): `GET https://translate.google.com/translate_tts?ie=UTF-8&q=<urlencoded>&tl=ru&client=gtx` (UA = desktop Chrome; `client=tw-ob` also works but was slower), returns MP3 (24 kHz). Text > ~190 characters returns HTTP 400 → split at sentence/clause/space boundaries into chunks ≤ 180 chars and fetch sequentially, prefetching chunk N+1 while N is being written. `ttsspeed=0.5` slows it down. One fixed voice. Bench: 1.6 s.
3. **Silero demo Space** (`SileroSpaceTts`, id `silero`, public Hugging Face demo, no account): Gradio **3.39** app at `https://neurosenko-tts-silero.hf.space`. `POST /run/predict` JSON `{"data":[TEXT,"Common"|"SSML",SPEAKER],"fn_index":2,"session_hash":"<11 chars>"}` → `{"data":[{"name":"/tmp/gradio/…/x.wav","is_file":true}],...}`; download `GET /file=<name>` → WAV PCM16 48 kHz mono. Speakers: `aidar, baya, kseniya, xenia, eugene` (+`random`). Silero stress marks use `+` before the stressed vowel (e.g. `зам+ок`). Bench: predict 2.5–3.7 s, download 3–15 s (public demo; may be asleep/cold — treat >60 s as failure with a clear message). Output `AudioSpec.wav()`. Fetch `/config` once to confirm `version` starts with `3.` and the dependency/fn_index of the TTS function (it is the dependency whose outputs include an `audio` component); fail with a clear message if the Space changed.
4. **ElevenLabs** (`ElevenLabsTts` + `ElevenLabsStt` + helper `ElevenLabsApi`, ids `elevenlabs`; needs `apiKey`; official). Base `https://api.elevenlabs.io`, header `xi-api-key`. Verified on the user's **free** key: `GET /v1/user/subscription` (tier, `character_count`, `character_limit`=10000, next reset unix), `GET /v2/voices?page_size=100` (21 premade voices incl. Sarah `EXAVITQu4vr4xnSDxMaL`, George `JBFqnCBsd6RMkjVDRZzb`, Roger, Alice, Lily, Brian…; `category` premade), `GET /v1/models` (`eleven_flash_v2_5`, `eleven_turbo_v2_5`, `eleven_multilingual_v2`, `eleven_v3`, `eleven_v4`, `eleven_v4_turbo` all support Russian), `POST /v1/text-to-speech/{voice_id}/stream?output_format=pcm_24000` body `{"text":…,"model_id":…,"voice_settings":{"stability":0.5,"similarity_boost":0.75,"style":0,"use_speaker_boost":true},"language_code":"ru"}` → raw PCM s16le 24 kHz streamed (first byte 0.8–1.2 s on bench); on free tier `pcm_44100` is **403 subscription_required** (use `pcm_24000`; also `pcm_16000`, `pcm_22050`, `mp3_22050_32`, `mp3_44100_64`, `opus_48000_32` work). Defaults to apply (from the product owner's research): stability 0.5, style 0 ("higher stability = monotone, much lower = chaotic"), similarity 0.75. For `eleven_v3`/`eleven_v4*` the text may contain **emotion tags in square brackets in English** (`[whispers]`, `[sighs]`, `[pause]`); for other models the SpeechText layer strips them — expose `supportsTags(model)`. `language_code` is only accepted by some models (flash/turbo v2.5, v3...) → if the API answers 400 mentioning it, retry without. **Not available on free (HTTP 403 `feature_not_available`/`subscription_required`)**: Voice Design via API (`/v1/text-to-voice/design`), instant voice cloning (`/v1/voices/add`), library voices — implement `designVoice` and `cloneVoice` in `ElevenLabsApi` anyway (they work on paid plans), but classify the 403 into a clear Russian message ("доступно только на платном тарифе ElevenLabs"), and let `ProviderInfo.cloning=true` with an honest `cloningNote` saying it requires a paid plan. Also implement `ElevenLabsApi.speechToSpeech(voiceId, PcmAudio|wav bytes, model="eleven_multilingual_sts_v2")` (multipart `audio`, `model_id`, `voice_settings`; verified 200 on free) returning MP3 bytes, and `ElevenLabsStt` (`POST /v1/speech-to-text` multipart `model_id=scribe_v1`, `language_code=rus`, `file` = WAV; verified 200 on free, 1.4 s for 3 s of audio, doesn't consume TTS characters). `quotaText()` from subscription. Never retry a 4xx.
5. **OpenRouter audio** (`OpenRouterTts`, `OpenRouterStt`, ids `openrouter-tts`, `openrouter-stt`; needs the user's OpenRouter `apiKey`; official, small paid pool but **free models exist**). Base `https://openrouter.ai/api/v1`. TTS: `POST /audio/speech` JSON `{"model":"fish-audio/s2.1-pro-free:free","input":TEXT,"response_format":"mp3"}` → raw MP3 (verified: 3.9 s, 71 KB). **Voice cloning works free**: add `"input_references":[{"type":"input_audio","input_audio":{"data":"data:audio/mpeg;base64,<ref>"}},{"type":"text","text":"<exact transcript of the reference>"}]` (verified 200, 13 s; keep the reference ≤ ~15 s / ≤ 200 KB; MP3 or WAV; transcribe/convert on the caller side). `heygen/heygen-voice-1-turbo:free` needs an explicit voice or a reference recording (400 otherwise). List TTS models dynamically: `GET /models?output_modalities=speech` (has `:free` ones), STT models: `GET /models?output_modalities=transcription`. STT: `POST /audio/transcriptions` JSON `{"model":"openai/whisper-large-v3-turbo","input_audio":{"data":"<base64 WAV>","format":"wav"},"language":"ru"}` → `{"text":…}` (verified; also `mistralai/voxtral-mini-transcribe-3-0`, `qwen/qwen3-asr-0.6b`). Keep `model` configurable (`model` config key). Transient SSL EOF errors happened: retry once on connection reset.
6. **Groq Whisper STT** (`GroqStt`, id `groq-stt`, needs `apiKey`, official, free tier): `POST https://api.groq.com/openai/v1/audio/transcriptions` multipart (`file` WAV/FLAC/MP3 — AAC/ADTS is **rejected**; `model=whisper-large-v3-turbo`, `language=ru`, `response_format=json`). Not yet timed: measure.
7. **Google Speech v2 (Chromium web-speech key)** (`GoogleSpeechStt`, id `google-stt`, unofficial, no account): `POST https://www.google.com/speech-api/v2/recognize?output=json&lang=ru-RU&key=REDACTED&maxresults=3` with `Content-Type: audio/l16; rate=16000` and the raw PCM as body. The response is **several JSON lines**; the first is `{"result":[]}`, the useful one holds `result[0].alternative[0].transcript` and `confidence`. Verified on the bench: 28 s for 7.4 s of audio mostly because of the 7 KB/s uplink; FLAC upload also works (needs an encoder — skip, raw PCM is fine). Mark `official=false`.
8. **F5-TTS Russian Space (cloning, slow)** (`F5SpaceTts`, id `f5-ru`): Gradio **5** Space `https://jyuviole-e2-f5-tts-rus.hf.space` (config at `/config`, API listing `/gradio_api/info` — very large; find the single-voice "basic TTS" endpoint: parameters ref audio (filepath), ref text, generation text, remove-silence, speed etc.). Protocol: upload ref audio `POST /gradio_api/upload`, then `POST /gradio_api/queue/join` `{"data":[…],"fn_index"|"api_name"…,"session_hash":…}` and read SSE from `GET /gradio_api/queue/data?session_hash=…` until `process_completed`; download the output file URL. Expect ~4 minutes per phrase (CPU Space): this provider is **studio-only**: expose `info().limitations` saying so and make `synthesize` honour cancel. If you cannot get it to complete within ~12 minutes of experiments, deliver a clean implementation that fails with a clear message and document exactly what happened.

## Shared pieces to implement
* `WebSocketClient` (pure Java, TLS via `SSLSocketFactory`, no deps) with unit tests against a local Java WebSocket echo/binary server (write the server side in the test) incl. fragmentation, masking, ping, close, 64-bit lengths.
* `TtsRegistry` / `SttRegistry`: lists all providers, `configure(all, Map<providerId, ProviderConfig>)`, lookup by id.
* `SpeechText` (static utility), all pure and heavily unit-tested:
  - `String forSpeech(String text, Opts)`: strip markdown (`**`, `#`, backticks, links → label, bullets), emoji/pictographs, URLs (say "ссылка"), collapse whitespace; **numbers → Russian words** (integers up to 10^12 with correct gender/case where cheap: "2 часа", "21 год", "5 минут"; decimals "3,5" → "три целых пять десятых"; percents, times `07:30` → "семь тридцать", dates `28.10.2026` → "двадцать восьмое октября две тысячи двадцать шестого года", ordinals `3-й`), common abbreviations ("т.е.", "и т.д.", "км", "кг", "°C"); keep it conservative: never mangle words.
  - tag handling: `Opts.keepEmotionTags` (true only for ElevenLabs v3/v4): keep `[whispers]`-style tags (English letters, spaces, commas only), otherwise strip them; always drop `[pause]`-less leftovers.
  - `PronunciationDict`: ordered list of (pattern → replacement, regex or literal, case-insensitive flag) persisted as JSON text (`toJson/fromJson`), applied last; default entries for "Джарвис"-style names are not needed. Provide `Silero` stress helper: `withStressPlus(String)` is NOT needed.
  - `splitSentences(String, maxChars)` for chunked streaming (first chunk short, ≤ 120 chars, for time-to-first-audio).
* `TtsCache`: file cache keyed by SHA-1 of (providerId|voice|model|speed|settings|text), stores the exact bytes + a tiny header JSON (codec/rate), LRU eviction by total size (`maxBytes`, default 64 MB) and age; atomic writes (temp + rename); thread-safe; `CachingSink` (wraps an AudioSink and records the stream so a second identical request replays from disk without network) — only commit the cache entry on `end()`, never on abort/error.
* `VoiceRegistry`-level helper `ProviderChain`: tries providers in the user's order for a request, falls back only on retryable/network/quota/geo errors (not on CANCELLED), but **never** falls back into providers flagged `slow` (F5) — add a `boolean slow()` default method on a sub-interface `SlowProvider extends TtsProvider` (your file).
