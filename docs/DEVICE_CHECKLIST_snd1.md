# Проверка на телефоне: snd1 (Z-01…Z-04)

Нужно, когда телефон доступен по ADB. На стенде не проверено: звук, вибрация, звонок, Telegram, реальный микрофон.

Важно: кнопки «Проверить», «Установить пакет CC0», выбор набора и загрузка своего файла появятся на экране настроек
после слияния `set1` (ключи в `docs/SND_SETTINGS.md`). До слияния эти шаги выполняются через журнал и `CueAssetCheck`/`Cues`.

## 0. Подготовка (один раз)

1. `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569; adb devices` — телефон должен быть в списке.
2. Сборка: `cd ~/jarvis-wt/snd1 && JV_APP_ID=app.jarvis.snd1 JV_APK_OUT=$PWD/build/outputs/snd1.apk bash build.sh debug`.
3. Установка своего варианта (не `app.jarvis`): `adb -s $D install -r build/outputs/snd1.apk`.
4. Запуск только под `tools/with-screen.sh`: `bash tools/with-screen.sh adb -s $D shell am start -n app.jarvis.snd1/app.jarvis.MainActivity`.
5. В приложении: Настройки → Обращение, разрешить микрофон и уведомления. Включить «Обращение» (wake).
6. Для журнала использовать экран «Журнал», фильтр «Обращение», уровень DEBUG (строки «Сигнал …»).

## 1. Сигнал начала по кнопке микрофона (Z-01, Z-02)

1. Не говорить в микрофон сразу: нажать кнопку микрофона (push-to-talk) при выключенном звуке телефона на «Обычный».
2. Ожидаемо: короткий звук набора «Хрусталь» (crystal) слышен до того, как Джарвис начнёт слушать; одиночный тик вибрации (18 мс).
3. В журнале DEBUG: «Сигнал «начало» (set:crystal:START, 320 мс)».
4. Сказать «Джарвис, который час» после звука. Ожидаемо: звук НЕ попал в распознанный текст (в журнале «Распознано (command …)» без слов от звука).
5. Оценить громкость: звук должен быть заметен, но не резать слух. Если тихо или громко — поменять `cue.volume` (0.1–1.0) и повторить. Записать значение и впечатление в отчёт.

## 2. Сигнал конца при паузе в речи

1. Нажать микрофон, сказать фразу, замолчать.
2. Ожидаемо: через ~550 мс после конца речи звучит сигнал конца («Хрусталь» вниз) и двойной тик вибрации; потом ответ агента.
3. В журнале: «Сигнал «конец» (set:crystal:STOP, 380 мс)».

## 3. Сигнал конца при ручной остановке

1. Нажать микрофон, не говорить, нажать ещё раз (отмена).
2. Ожидаемо: звучит сигнал конца; «Микрофон выключен» в журнале идёт раньше сигнала (при выключенном обращении микрофон закрывается до звука).

## 4. Ошибка: ничего не услышал

1. Нажать микрофон и молчать 7 секунд.
2. Ожидаемо: сигнал ошибки (ниже и тише) и подсказка «Не услышал команду». Вибрации нет.

## 5. Обращение по слову (wake)

1. Включено «Обращение»; сказать «Джарвис» и затем паузу.
2. Ожидаемо: сигнал начала после распознавания обращения, потом слушание команды; сигнала на каждую фразу в комнате нет.
3. Сказать «Джарвис, включи музыку» одной фразой: сигнала начала нет (команда уже в той же фразе), ответ идёт сразу. Записать, так ли это ожидаемо для владельца.

## 6. Тихий режим и «Не беспокоить»

1. Громкость звонка → «Вибрация»: сигналы не звучат, вибрация остаётся. Журнал: «тихий режим или «Не беспокоить»».
2. «Не беспокоить» (приоритет/полная тишина): то же самое.
3. Вернуть «Обычный»: звук возвращается.

## 7. Звонок (Z-03)

1. Включить обращение. Позвонить на телефон с другого номера (или сделать тестовый звонок), ответить.
2. Ожидаемо: в строке состояния голоса «Идёт звонок: Джарвис не слушает»; журнал WAKE: «…Идёт звонок…» INFO. Сигналов во время звонка нет.
3. Положить трубку. Ожидаемо: через ~1,2 с «Микрофон снова у Джарвиса», обращение снова слушает.

## 8. Telegram: запись голосового сообщения (Z-03, сценарий владельца)

1. Включить обращение, убедиться, что Джарвис слушает (строка состояния «Ожидание»).
2. В Telegram зажать кнопку голосового сообщения и начать запись. Ожидаемо в пределах 300 мс: журнал «Микрофон занят другим приложением: Джарвис уступил микрофон…»; строка состояния показывает «Микрофон занят другим приложением».
3. Записать голосовое сообщение в Telegram, отпустить. Ожидаемо: через ~1,2 с журнал «Микрофон снова у Джарвиса». Голосовое сообщение в Telegram записалось полностью (это и есть главная проверка).
4. Повторить 3 раза подряд. Ожидаемо: каждый раз возвращается. Если Джарвис не возвращается: журнал «Микрофон не освободился: прослушивание остановлено» и обращение выключено (включить вручную).
5. Во время записи в Telegram Джарвис не должен говорить вслух и не должен отвечать на собственный звук.

## 9. Отмена во время занятого микрофона

1. Пока Telegram держит микрофон, нажать кнопку микрофона Джарвиса. Ожидаемо: тост «Микрофон занят другим приложением», без сигналов.

## 10. Предпросмотр набора (только по нажатию)

1. Для каждого набора из `docs/SOUNDS.md` (10 встроенных) нажать «Проверить» (когда экран настроек его выведет): проигрываются начало и конец.
2. Ожидаемо: звук не звучит сам при открытии экрана; звучит только по нажатию.
3. Набор `oga_clicks` доступен только после «Установить пакет CC0» (см. пункт 11).

## 11. Пакет CC0 (кнопка)

1. Нажать «Установить пакет CC0». Ожидаемо: загрузка около 231 КБ, затем «Набор установлен»; в `filesDir/cues/packs/oga-ui/` 12 файлов OGG.
2. Выбрать набор `oga_clicks`, нажать микрофон. Ожидаемо: короткие щелчки (начало и конец по 222 мс, ошибка 374 мс).
3. Оценить, нужен ли набор вообще: записать впечатление.

## 12. Свой звук (файл)

1. Выбрать файл OGG до 300 КБ и до 3 с как «Свой звук начала». Ожидаемо: сохранён; при нажатии микрофона звучит он.
2. Выбрать WAV на 4 с: ожидается сообщение «Звук длиннее 3 секунд», старый файл не меняется.
3. Выбрать файл больше 300 КБ: «Файл больше 300 КБ».
4. Выбрать `.txt`: «Формат не поддерживается».

## 13. Скорость речи (Z-04)

1. Настройки → Голос: «Скорость речи» 0.7, затем 1.0, затем 1.4.
2. Для ElevenLabs и Edge: один и тот же текст, три прослушивания. Ожидаемо: 0.7 заметно медленнее, 1.4 заметно быстрее.
3. Для Google Translate: 1.4 звучит как 1.0 (сервис только замедляет), 0.7 медленнее.
4. Для Silero и OpenRouter: скорость не меняет звук (документировано).
5. Кэш: та же фраза при другой скорости не берётся из кэша (ключ кэша включает скорость): первый ответ после смены скорости идёт через синтез, а не мгновенно.

## 14. Регрессия

1. Обычный разговор с Джарвисом без обращения, текстовый чат: сигналов нет.
2. Запись в студии (запись образца голоса): сигналов нет.
3. Удалить свой вариант: `adb -s $D uninstall app.jarvis.snd1`.

## Что записать в отчёт

* Громкость сигналов по шагам 1 и 6 (субъективно, 1–5).
* Сработала ли уступка Telegram (шаг 8, 3 повтора), время возврата по журналу.
* Голосовое сообщение в Telegram записалось полностью: да/нет.
* Текст шага 5.3 (совпало ли с ожиданием владельца).
