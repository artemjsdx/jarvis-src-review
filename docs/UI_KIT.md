# UI kit (design system)

Code: `ui/Ui.java` (tokens, surfaces, buttons), `ui/Widgets.java` (rows, toggles, fields, sheets' building blocks),
`ui/motion/Motion.java` (durations, curves, transitions), `ui/theme/` (theme resolution, window bars, state carry-over),
`core/design/` (pure palette spec, Bézier and spring curves: unit-tested on the JVM).
Gallery: `tools/preview.sh UiKitGallery` renders `build/preview/kit_gallery_{dark,light}_{1,2}.png`.

## Tokens

| Token | Value | Use |
|---|---|---|
| `Ui.S.XS / SM / MD / LG / XL` | 4 / 8 / 12 / 16 / 24 dp | every margin and padding; all on a 4 dp grid |
| `Ui.S.GAP` | 12 dp | space between cards (cards are drawn inset by GAP/2, so `Ui.card` needs no margins) |
| `Ui.S.RADIUS_CARD` | 18 dp | cards, dialogs (22–26 dp for sheets) |
| `Ui.S.RADIUS_FIELD` / `RADIUS_BUTTON` | 14 dp | fields, buttons, segmented bar |
| `Ui.S.RADIUS_CHIP` | 20 dp | chips and pills |
| `Ui.hairline()` | 0.75 dp (min 1 px) | every border (`Ui.outlined`, field focus) |
| `Ui.P.*` | see `core/design/PaletteSpec` | colours. `text`/`text2` ≥ 4.5:1, `text3`/`accent` ≥ 3:1 on `bg0`/`bg1` (both themes, tested) |
| `Ui.TITLE / BODY / CAPTION / MONO` | 20 / 15 / 12 / 12.5 sp | type scale (`Ui.text(c, s, kind)`) |

Palette values for the two themes live in `core/design/PaletteSpec.java`; `Ui.P` is a runtime copy. Change colours there and
run `tools/run-tests.sh app.jarvis.core.design.PaletteContrastTest`.

## Building a screen

* Sections: `Widgets.sectionTitle(c, "Подключение")` (= `Ui.section`), then one or more `Widgets.card(c)` (= `Ui.card`).
* Rows in a card: `Widgets.row(c, icon, title, subtitle, trailing, onClick)`; add `Widgets.divide(card)` between rows.
* Fields: `Widgets.fieldBox(c, Widgets.field(...))` (border turns accent on focus, animated).
* Buttons: `Ui.button(c, label, icon, Ui.BTN_PRIMARY|GLASS|GHOST|DANGER, onClick)`; press feedback is built in (scale 0.97, spring back).
* Toggles: `Widgets.toggle(c, on, listener)`: spring thumb, track colour, haptic tick.
* Segmented choice: `Widgets.segmented(c, labels, index, listener)`.
* Overlays: `host.overlays().showDialog / showSheet / toast` (animated by `Motion`).
* Layout rules:
  * use `Ui.lpwm(weight, l, t, r, b)` for weighted children; never `Ui.lpm(0, …)` (zero width without weight is invisible;
    `UiSourceLintTest` fails on it and on `addView(new View(…))` without a size);
  * use `Ui.space(c, w, h)` for spacers, never a bare `new View(c)` in a layout;
  * use `Ui.rowTop(c)` when the row's children have different top and bottom margins (a centred row shifts them);
  * never `setSingleLine(true)` on a weighted label (it vanishes on ART); use `setMaxLines(1)` + ellipsize.

## Motion

* Durations: `Motion.D_FAST 120`, `D_BASE 200`, `D_SLOW 320`, `D_XSLOW 480` ms. Curves: `Motion.DECELERATE` (enter),
  `ACCELERATE` (exit), `STANDARD`, `SPRING` (damped, one slight overshoot).
* Ask for durations, never time them yourself: `Motion.move(base)` returns 0 unless the mode is FULL; `Motion.fade(base)` caps fades at
  80 ms in REDUCED and returns 0 in OFF. `Ui.ms(base)` is `move(base)` (kept for old call sites).
* Modes (`ui.motion` setting; Settings → Внешний вид → Анимация): **full** (as designed), **reduced** (no movement, fades ≤ 80 ms),
  **off** (instant). If Android's animator scale is 0, full becomes off.
* Overlays: `Motion.enter(view, Kind.DIALOG|SHEET|TOAST|POPUP|FADE_THROUGH)` and `Motion.exit(view, kind, endAction)`.
* Screens: `Shell.navigate` slides dock neighbours along a shared axis (direction = dock order) and fades other screens through.
* Borders/colours: `Motion.stroke(drawable, width, from, to, ms)`.
* Haptics: `Motion.tick(view)` on toggles.
* Never run an animation that ignores the mode; for a new kind, add it to `Motion` and give it a reduced and an off branch.

## Theme

* `ui.theme` = `dark` | `light` | `system`. Changing it in Appearance calls `Host.applyTheme()`; `MainActivity.rebuildTheme` builds a
  fresh `Shell` in the new palette, navigates to the same screen and argument, and copies field text and scroll offsets
  (`ui/theme/ViewState`). `system` also follows `onConfigurationChanged`.
* Views keep the colours they were built with: after `Ui.setDark` you must rebuild (the shell does this for you).
* Status and navigation bar icons follow the theme (`ui/theme/Theme.applyWindow`).

## Icons

* `app/res/drawable/ic_*.xml` are generated by `tools/gen-icons.py` from Lucide (ISC; list in `THIRD_PARTY.md`). Do not edit them by hand.
  Add a name to the `ICONS` dict and run `python3 tools/gen-icons.py`.
* Style: 24 viewBox, stroke 1.8 dp, round caps and joins, no fill. `IconSetTest` enforces it.
* The generator expands compact SVG arc flags (`1012` → `1 0 12`). Before this, Android dropped those arcs and `ic_brain`
  and `ic_zap` drew empty.
* `ic_notify` is the status-bar glyph (hand-drawn with a filled dot) and is excluded from the style test.

## Remaining hard-coded spots (owned by other agents; fix when you touch the file)

* Literal spacing: `Ui.lpm(` / `Ui.dp(` with numbers in: `settings/LlmPage` (62), `studio/DubTab` (35), `chat/ChatAdapter` (33),
  `screens/HomeScreen` (28), `screens/LogScreen` (27), `screens/AgentScreen` (26), `studio/PronTab` (25), `studio/CloneTab` (25),
  `voiceui/WakeSettingsPage` (23), `files/FileViewer` (23), `voiceui/VoiceSettingsPage` (19), `screens/FilesScreen` (18).
  Replace with `Ui.S.*`.
* Bare `new View(...)` in layouts (check each has an explicit size or use `Ui.space`): `screens/AgentScreen:77`,
  `screens/LogScreen:285,293`, `Dialogs:88,134`, `files/AudioSheet:215`, `chat/ModelSheets:144`, `files/FileViewer:216`,
  `files/FolderPicker:116`, `files/TextEditorSheet:223`. `Shell.stateDot` and `OverlayHost` scrim are sized.
* Settings rows with no icon: memory rows in `settings/SandboxPage` and the provider rows in `settings/LlmPage:105,758`
  pass `0` as the icon; give each a meaning (for example `ic_pen_line` for response-style rules, `ic_brain` for facts).
* Tool list: every tool in `settings/SandboxPage:131` uses `ic_wrench`; pick by group (`ic_globe` web, `ic_folder` files, `ic_usb` ADB,
  `ic_terminal` shell).
* Rows with asymmetric margins: audit with `rg -n "Ui.lpm\(.*, [0-9]+, [0-9]+\)" app/src/main/java/app/jarvis/ui` and check the
  parent is `Ui.rowTop` when top ≠ bottom.
* `Ui.row` centres children vertically; rows that sit under a `lpm` with a bottom margin should move to `Ui.rowTop`.
