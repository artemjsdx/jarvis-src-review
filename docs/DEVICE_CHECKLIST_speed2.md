# Проверка speed2 на телефоне (нужно сделать, когда ADB снова доступен)

Все шаги — только для пакета `app.jarvis.speed2`. Звук и микрофон не используем, см. правила задания.

Подготовка
1. `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569; adb -s $D devices` — устройство должно быть `device`.
2. `JV_APP_ID=app.jarvis.speed2 JV_APK_OUT=$PWD/build/outputs/speed2.apk bash build.sh debug`, затем `adb -s $D install -r build/outputs/speed2.apk`.
3. Открыть Настройки → Голос, выставить `direct.confirm`=live (базовый замер), тест-провайдер Edge.

Замер «до первого звука» (5 запусков на каждый сценарий, медианы; голос через внешний файл — `tools/dev-*.sh` или SpeedE2E по `docs/SPEED.md` раздел 5)
4. Прямая команда («пауза» при играющей музыке): записать `to_sound` из `perf` в журнале (`TraceStore` → `turns.jsonl`).
5. Тот же сценарий с `direct.confirm`=fast: ожидается «Поставил на паузу.» без обращения к LLM (в трассе нет `llm_request`).
6. Одно-инструментная команда («создай заметку …») с `direct.confirm`=auto и `ack.mode`=voice: ожидается реплика «Секунду.» (если фраза уже в кэше), затем ответ.
7. Вопрос без инструментов («что такое кэш процессора?»): проверить, что реплика НЕ звучит при ответе быстрее 900 мс.

Опережающий синтез
8. Длинный ответ (3–4 предложения), `tts.lookahead`=true и false: в трассе `tts.gap_ms_max` и `tts.gap_ms_total` должны быть меньше при true.

Удержание фразы
9. Сказать «Джарвис, включи музыку и» и паузу 2 с: ассистент должен выполнить только «включи музыку» (без продолжения), журнал STT: «жду продолжение».
10. Сказать «Джарвис, включи музыку и» + «следующий трек» быстро подряд: одна команда из двух частей.

Фон и ошибки
11. Выключить сеть (режим полёта на 20 с) во время ответа: ожидание «Секунду.» не должно зациклиться, ход завершается ошибкой без зависания.
12. Проверить журнал на токены: в `llm` трассы `tokens_cached` > 0 для `anthropic/*` со второго хода (если выбран Anthropic через OpenRouter).

Очистка
13. `adb -s $D uninstall app.jarvis.speed2`.

Ожидаемое: нет крашей; реплика не звучит поверх ответа; ответы без «двойного» текста.
