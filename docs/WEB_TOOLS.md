# Веб-инструменты агента: поиск, чтение страниц, документация

Реализация: `app/src/main/java/app/jarvis/core/web/**` (чистая Java, без сторонних библиотек), регистрация в
`core/tools/WebTools.java`. Числа ниже — замеры на стенде (vivo, Termux, сеть стенда: исходящая скорость ~7 КБ/с,
RTT 0,5–2 с). На целевом телефоне и в мобильной сети будут другие.

## Инструменты

| Инструмент | Аргументы | Что возвращает |
|---|---|---|
| `web_search` | `queries: string[1..6]` (обязательно), `limit` 1–10 (по умолчанию из настроек, 5), `recency` day\|week\|month\|year, `site` (хост) | `{ok, backend, ms, results:[{query, error?, hits:[{title,url,snippet,source,published?}]}]}` |
| `web_fetch` | `url` (обязательно), `format` markdown\|text\|raw (по умолчанию markdown), `max_chars` 1000–200000, `offset` | `{ok, url, finalUrl, title, status, contentType, format, text, truncated, nextOffset\|null, totalChars, links:[{text,url}]}` (до 30 ссылок) |
| `docs_search` | `query` (обязательно), `limit` 1–10 | `{hits:[{path, score, snippet}], indexed}` по `downloads/` и `docs/` песочницы |

* `web_search` и `docs_search` помечены `sideEffects=false`: цикл агента выполняет их параллельно с другими чтениями.
* Ошибки всегда с русским текстом пользователя (`ToolResult.error`) и техническим описанием в журнале.
* Бинарные ответы (PDF, офис, изображения, архивы) не разбираются: `web_fetch` возвращает `binary:true` и подсказку
  «используйте download, затем откройте файл в разделе Файлы».

## Поиск: бэкенды и порядок

Настройка `web.search.backend`: `auto` (по умолчанию) | `openrouter` | `brave` | `tavily` | `exa` | `searxng` | `ddg`.

* `auto`: по порядку те, что настроены: **Brave → Tavily → Exa → OpenRouter (web-плагин) → SearXNG → DuckDuckGo**.
  DuckDuckGo всегда последний (без ключа).
* Явно выбранный бэкенд работает один; если ключа нет, возвращается «не настроен: добавьте ключ в настройках».
* Бэкенд с ошибкой 401/402/403/429/5xx или с таймаутом пропускается **10 минут** (cooldown), переходим к следующему.
  Прочие ошибки (непонятный ответ, сеть) — переход к следующему без штрафа.
* Тайм-ауты: 12 с на запрос (первый бэкенд получает 60 % бюджета, если за ним есть другие), 20 с на весь вызов.
  Каждый запрос идёт в своём потоке; отмена (`ctx.cancel`) прерывает HTTP-соединения.
* Дедупликация: ссылки нормализуются (нижний регистр хоста, без `www.`, без фрагмента, без `utm_*`, `fbclid`,
  `gclid`, `yclid`, `mc_*`, `ref`, `ref_src`, `_ga`, без завершающего `/`), повторы убираются между всеми запросами
  одного вызова (первое вхождение выигрывает).

### Поля и ключи

| Ключ | Где | Назначение |
|---|---|---|
| `key.openrouter` | Secrets | уже есть для LLM; используется для web-плагина |
| `key.brave`, `key.tavily`, `key.exa` | Secrets | необязательно |
| `web.searxng.url` | Settings | адрес своего SearXNG (`/search?format=json` должен быть разрешён) |
| `web.search.backend` | Settings | см. выше |
| `web.search.openrouterModel` | Settings | по умолчанию `deepseek/deepseek-v4.1-flash` |

### OpenRouter: выбор модели (замер 2026-10-29, 3 запроса × 4 модели)

Запросы: «погода Гомель», «asyncio event loop python docs», «курс доллара к рублю сегодня». Запрос: chat completion с
`plugins:[{id:"web",max_results:5}]`, `max_tokens:150`, `temperature:0`, `usage.include`.

| модель | ответ | цитаты (url_citation) | задержка, с (3 запроса) | стоимость, USD (3 запроса) |
|---|---|---|---|---|
| `deepseek/deepseek-v4.1-flash` | 3/3 | 5 / 5 / 5 | 9,3 / 5,3 / 9,0 | 0,0073 + 0,0073 + 0,0072 |
| `google/gemini-2.5-flash-lite` | 2/3 (одна 429 от провайдера) | 5 / 5 / — | 7,2 / 9,2 / 5,6 | 0,0076 + 0,0073 |
| `perplexity/sonar` | 3/3 | 28 / 5 / 30 | 9,0 / 14,1 / 7,5 | 0,0171 + 0,0147 + 0,0141 |
| `openai/gpt-5-nano` | 3/3 | **0** (плагин не сработал) | 5,9 / 20,1 / 9,0 | 0,0003 + 0,0001 + 0,0001 |

Итог: **deepseek-v4.1-flash** — дешёвый, стабильный, 5 цитат с заголовками и URL; выбран по умолчанию. Sonar даёт
больше цитат, но вдвое дороже. gpt-5-nano без цитат непригоден. Расход на оценку: **0,083 USD** (лимит 0,3 USD).

Live-вызов инструмента через `OpenRouter.complete` (`WebLiveSmokeTest`, 1 запрос «погода Гомель»): 9,3 с, prompt 5202
токенов, completion 150, стоимость 0,0073 USD, 3 результата показаны из 5 (Яндекс.Погода, Gismeteo, exa.ai).
Два запроса через `SearchRouter` параллельно: 7,2 с суммарно, оба ответил OpenRouter.

### DuckDuckGo

`https://html.duckduckgo.com/html/?q=`, разбор `a.result__a` / `a.result__snippet`, ссылки `uddg=` раскрываются.
HTTP 202 или страница «unusual traffic» → «недоступен» (cooldown), без повторов. Live-проверка на стенде: **5 результатов**
(при более ранних запусках этот сервис из сети стенда отвечал 202 — поведение нестабильно, поэтому он только последний).

### Brave, Tavily, Exa, SearXNG — не проверены в сети

На стенде нет ключей Brave/Tavily/Exa и нет инстанса SearXNG (проверено: в `keys.py` их нет). Парсеры и запросы
проверены записанными ответами в `app/src/test/resources/web/` (`brave.json`, `tavily.json`, `exa.json`,
`searxng.json`) и локальным сервером (`SearchBackendsTest`: заголовок ключа, кодирование запроса, `freshness`, 401 →
cooldown). Живой вызов — после появления ключа: `JV_LIVE=1` + ключ в Secrets.

## Чтение страниц (`web_fetch`)

* HTTP GET с браузерным User-Agent, `Accept-Language: ru,en`, `Accept-Encoding: gzip` (распаковка своя, лимит считается
  по распакованному потоку).
* Редиректы вручную: до 5 переходов; **переход с https на http запрещён**; относительные `Location` разрешаются.
* Лимит источника 3 МиБ; при превышении `hint` «показана только начальная часть», `truncated:true`.
* Кодировка: BOM → заголовок `charset=` → `<meta charset>` (заголовок ISO-8859-1 уступает meta) → UTF-8, если корректна,
  иначе windows-1251. Незавершённый хвост UTF-8 при обрезке не считается ошибкой.
* HTML: отбрасываются `script, style, noscript, template, svg, iframe, nav, footer, aside, form, head, title, object,
  button, select, textarea, dialog`, элементы с `hidden`, `aria-hidden=true`, `display:none`, `visibility:hidden`,
  блоки с токенами `cookie, consent, gdpr, advert, sidebar, breadcrumb, newsletter, popup, share, social` в id/class.
  Основной блок: `<article>`/`<main>`/`role=main` с ≥ 200 симв. текста, иначе `<body>`; затем спуск по контейнерам
  (div, section, article, main, body, td…), пока один ребёнок держит ≥ 80 % текста (ссылки не считаются).
* Разметка: заголовки `#`, абзацы, списки (`-`, `1.`, вложенные с отступом), `**жирный**`, `*курсив*`, `` `код` ``,
  блоки кода ```` ``` ````, ссылки `[текст](абс-url)` (якоря, `javascript:`, `mailto:` — только текст), `[изображение: alt]`,
  таблицы — выровненная сетка `| … |`; вложенные таблицы сплющиваются в ячейку, одноколоночные — layout-таблицы — как блоки.
* Пагинация: `offset` и `nextOffset` в символах; срез не разрывает суррогатные пары. Проверено: 400 строк с эмодзи
  собираются обратно без потерь.
* Повтор `offset` не кэшируется: каждое чтение заново скачивает страницу.

## Документы (`docs_search`)

* Индекс по `downloads/` и `docs/` песочницы: расширения `md txt html htm json py java kt js ts sh xml csv yaml yml rst log
  cfg ini toml c h cpp go rs gradle properties tex`; файлы до 512 КиБ, до 2000 файлов, глубина 8, скрытые каталоги пропускаются.
* HTML индексируется как текст (разметка и `<script>` не попадают в индекс).
* Обновление при каждом поиске: перечитываются только файлы с изменившимся mtime или размером, исчезнувшие удаляются.
* Ранжирование: упрощённый BM25 по словам (≥ 2 символов, регистр не важен, без стемминга). Имя файла, совпавшее
  со словом, даёт дополнительный вес. Фрагмент — 220 символов вокруг первого совпадения.
* Ограничение: нет стемминга и морфологии («кошка» ≠ «кошки»); поиск по фразам не делается.

* `app/src/test/java/app/jarvis/core/web/*` и `core/tools/WebToolsTest`: парсеры всех бэкендов на записанных ответах,

## Ограничения

* PDF, DOCX, XLSX и т. п. не разбираются (только подсказка про `download`). Для PDF нужен отдельный парсер — не взят.
* JavaScript-страницы (SPA без серверного рендера) дают пустой или короткий текст; браузера в приложении нет.
* Нет кэша страниц и результатов поиска; каждый вызов идёт в сеть.
* `web_search` для OpenRouter расходует токены и деньги владельца: около 0,007 USD на запрос (модель по умолчанию).
* DuckDuckGo нестабилен (202); cooldown 10 минут.
* Бэкенды Brave/Tavily/Exa/SearXNG в сети не проверялись (нет ключей/инстанса на стенде).
