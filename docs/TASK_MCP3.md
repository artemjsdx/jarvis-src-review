2. **Voice**:
   * `voice_state`: VoiceController state, wake state, mic permission, `MicArbiter` state if `snd1` landed (reflect, tolerate absence), current TTS/STT chains and which providers are in cooldown (+ remaining seconds), TTS cache stats.
   * `voice_speak(text, provider?, voice?, speed?)` → synthesizes through the REAL provider chain into a file under `files/mcp/audio/` (no playback unless `output=speaker` and `mcp.allowAudio`); returns `{provider, voice, chars, bytes, durationMs, firstByteMs, totalMs, cacheHit, path, cleanedText}` (cleanedText = after `SpeechText.clean`).    * `voice_stt_file(path|base64, provider?)` → decode the audio (WAV direct; MP3/OGG/Opus/AAC through `MediaExtractor`+`MediaCodec` to 16 kHz mono PCM) and run the STT chain (or the named provider); return `{text, provider, ms, attempts, bytesSent, format}`.
   * `voice_inject(path|base64, mode=command|wake, speak=false)` → feeds the audio into the voice pipeline exactly like the e2e `FakeMic` does (segmenter → STT → wake/command → agent → TTS), with the speaker silenced (record TTS output to a file instead; `speak=true` needs `mcp.allowAudio`); waits for the turn to finish (timeout 90 s) and returns the turn's `TurnTrace` JSON, the transcript, the agent reply and the TTS output path. This is the end-to-end latency test the owner cares about.
   * `tts_cache(action=stats|clear|list)`; `wake_state`, `wake_arm(on)` (honour `mcp.allowAudio`: arming the wake listener opens the microphone), `mic_level` (allowAudio).
