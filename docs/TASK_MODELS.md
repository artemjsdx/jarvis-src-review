## Facts to verify in code

OpenRouter's `/models` (public, no key) has rich data per model: `context_length`, `top_provider.{context_length,max_completion_tokens,is_moderated}`, `supported_parameters` (e.g. `tools`, `reasoning`, `include_reasoning`, `temperature`, `top_p`, `max_tokens`, `response_format`, `structured_outputs`), `architecture.{input_modalities,output_modalities}`, `pricing`.
