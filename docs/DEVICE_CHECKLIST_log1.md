# Проверка на телефоне: журнал (log1)

Выполнять, когда ADB до vivo I2407 снова доступен. До этого всё ниже не проверено. Не запускать ничего, что издаёт звук или использует микрофон без явного разрешения владельца.

Подготовка (один раз):
1. `export ANDROID_ADB_SERVER_PORT=5038; D=10.61.19.159:38569; adb devices` — телефон должен быть в списке. Если нет, ждать 30 с и повторить; не делать pair/connect.
2. Собрать вариант: `cd ~/jarvis-wt/log1 && JV_APP_ID=app.jarvis.log1 JV_APK_OUT=$PWD/build/outputs/log1.apk bash build.sh debug`.
3. Установить: `adb -s $D install -r build/outputs/log1.apk`. Открыть через `JV_DEVICE=$D JV_PKG=app.jarvis.log1 bash tools/with-screen.sh …` (правило Wave 3, pkg `app.jarvis.log1`).

Проверки:
1. **Место ошибки в живом журнале (L-01).** В чате задать запрос при пустом или неверном ключе LLM. Открыть «Журнал». Ожидание: строка ERROR с красной строкой «Где: <Файл.java>:<строка> in <метод>» (моноширинным шрифтом). Скриншот строки.
2. **Технические детали (L-01).** Открыть эту строку. Ожидание: ниже текста — «Технические детали: показать». Нажать. Видны «Поток», «Приложение» (версия и git-ревизия), «Android», «Устройство», «Свободно памяти», «Исключение», «Отпечаток», затем стек. Скриншот. Нажать «Копировать», вставить в заметки: в тексте есть строка «Где» и стек.
3. **Сжатие стека.** Стек длиннее экрана: прокручивается, текст выделяется долгим нажатием (selectable). Ожидание: не обрезается, не падает.
4. **Crash-строка (L-01 глобальный перехват).** Вызвать падение можно только тестовой сборкой; пропустить, если нет тестовой сборки. Если падение было: в журнале строка «Необработанное исключение в потоке …» с «Где:» и `crash/last.txt` в файлах приложения.
5. **Фильтр (L-04).** Строки «Распознано (wake …)» не видны при «Все». Выбрать «Отладка»: они появляются. Вернуть «Все», ввести текст в поиск (например «wake»): появляются и они, с подсветкой найденного текста.
6. **Сводка wake (L-04).** Включить режим «Джарвис» (нужен микрофон — делать только с разрешения владельца, говорить рядом с телефоном). Сказать несколько фраз. Ожидание: в журнале ОДНА строка «за 10 мин: N фрагментов, M обращений», которая растёт на месте (не добавляет новых строк). Сделать скриншот до и после.
7. **Кнопка «Что делать» (L-05).** Вызвать строку «Ошибка микрофона: Android не отдаёт звук микрофона …» (это бывает, когда приложение в фоне без разрешённой службы: выключить режим «Джарвис», свернуть приложение на 30 с и включить его снова — если строки нет, отметить «не воспроизвелось»). Открыть строку, нажать «Открыть настройки фона». Ожидание: открывается страница «Фон» Jarvis. Скриншот.
8. **Окно события (L-03).** Открыть любую строку журнала. Ожидание: фон за шторкой размыт (поверхность glass1), а не только затемнён. Если не размыт — отметить: это ожидает merge glass1 и не относится к коду log1.
9. **Переключатель уровней (L-02).** Открыть журнал: сегменты «Все / Предупр. / Ошибки / Отладка» видны и переключаются. Замена на стеклянную каплю — после merge glass1 (`LogScreen.buildLevelFilter`).
10. **Статус «Ожидание» (H-03).** На главном экране: режим «Джарвис» выключен → «Ожидание». Включён → «Жду обращения». Отправить запрос в чат → «Думаю», затем «Выполняю инструмент» (если был инструмент), затем «Говорю» (если озвучка включена) и снова «Ожидание»/«Жду обращения». Записать в таблицу: что показано, что ожидалось.
11. **Скриншот в настройках (S-18).** На телефоне:
    a. Открыть Jarvis → Настройки (главный экран). Нажать кнопки громкости вниз + питание: если запрет — записать текст всплывающего сообщения дословно и сделать фото экрана.
    b. Повторить на странице LLM с открытым полем ключа (пароль, только просмотр, не вводить реальный ключ).
    c. Повторить на странице ADB (сопряжение), с открытым системным диалогом «Сопряжение по коду», если владелец его открывает.
    d. На каждом шаге, пока экран открыт: `adb -s $D shell dumpsys window windows | grep -iE "mCurrentFocus|secure|FLAG_SECURE|DISABLE_SCREENSHOT"`. Записать строки с `mCurrentFocus` и любым `SECURE`/`FLAG_SECURE`.
    e. Ожидание: если на шаге d найдено окно с `SECURE` — его владелец и есть источник (записать заголовок окна). Если ни на одном шаге нет `SECURE`, а скриншот всё равно запрещён — источник вне Jarvis (оболочка vivo), записать как есть.
12. **Удаление варианта.** `adb -s $D uninstall app.jarvis.log1`.

Что записать в отчёт: номера пунктов с результатами, скриншоты (путь в `build/`), вывод шага 11d дословно.
